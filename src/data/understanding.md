# Doubling example

The canonical table contains nine synthetic observations, one per integer step
from 0 to 8. The initial value is 1 and `y = 2^x`. Values have no real-world
unit. The Overview and Data and queries tabs share the full chart through a
block reference. First five steps filters the same table to `x <= 4` and uses
the same chart component with its own axis scale.

For a real book, replace the sample with a documented source and a reproducible
transform. Keep the grain, units, and assumptions alongside the table.
